# Tools Cheatsheet

| Name                    | Purpose                                               | Link                                                                                                           | Notes                                     |
| ----------------------- | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| Nmap                    | Network discovery, port scanning, service enumeration | [https://nmap.org](https://nmap.org/)                                                                          | Core recon tool; supports NSE scripts     |
| Metasploit Framework    | Exploitation framework for vulnerabilities            | [https://www.metasploit.com](https://www.metasploit.com/)                                                      | Use `msfconsole`; integrates with Nmap    |
| Burp Suite              | Web application testing and interception proxy        | [https://portswigger.net/burp](https://portswigger.net/burp)                                                   | Essential for web pentesting              |
| Wireshark               | Network traffic capture and analysis                  | [https://www.wireshark.org](https://www.wireshark.org/)                                                        | Useful for protocol and packet inspection |
| Nikto                   | Web server vulnerability scanner                      | [https://cirt.net/Nikto2](https://cirt.net/Nikto2)                                                             | Noisy but fast web checks                 |
| Gobuster                | Directory, DNS, and virtual host brute forcing        | [https://github.com/OJ/gobuster](https://github.com/OJ/gobuster)                                               | Common for web enumeration                |
| Dirsearch               | Web path brute forcing                                | [https://github.com/maurosoria/dirsearch](https://github.com/maurosoria/dirsearch)                             | Python-based alternative to Gobuster      |
| Hydra                   | Online password brute-force tool                      | [https://github.com/vanhauser-thc/thc-hydra](https://github.com/vanhauser-thc/thc-hydra)                       | Supports many protocols                   |
| John the Ripper         | Offline password cracking                             | [https://www.openwall.com/john/](https://www.openwall.com/john/)                                               | Use with hash extraction tools            |
| Hashcat                 | GPU-accelerated password cracking                     | [https://hashcat.net/hashcat/](https://hashcat.net/hashcat/)                                                   | Very fast; steep learning curve           |
| SQLmap                  | Automated SQL injection exploitation                  | [https://sqlmap.org](https://sqlmap.org/)                                                                      | Highly effective but detectable           |
| Aircrack-ng             | Wireless network auditing                             | [https://www.aircrack-ng.org](https://www.aircrack-ng.org/)                                                    | Wi-Fi cracking and monitoring             |
| Netcat                  | Network utility for reading/writing connections       | [https://nmap.org/ncat/](https://nmap.org/ncat/)                                                               | Known as the “TCP/IP Swiss army knife”    |
| Tcpdump                 | CLI packet capture tool                               | [https://www.tcpdump.org](https://www.tcpdump.org/)                                                            | Lightweight alternative to Wireshark      |
| LinPEAS                 | Linux privilege escalation enumeration                | [https://github.com/carlospolop/PEASS-ng](https://github.com/carlospolop/PEASS-ng)                             | Post-exploitation staple                  |
| WinPEAS                 | Windows privilege escalation enumeration              | [https://github.com/carlospolop/PEASS-ng](https://github.com/carlospolop/PEASS-ng)                             | Run on compromised Windows hosts          |
| Enum4linux-ng           | SMB and Windows enumeration                           | [https://github.com/cddmp/enum4linux-ng](https://github.com/cddmp/enum4linux-ng)                               | Improved enum4linux                       |
| BloodHound              | Active Directory attack path analysis                 | [https://github.com/BloodHoundAD/BloodHound](https://github.com/BloodHoundAD/BloodHound)                       | Requires SharpHound data                  |
| Snort                   | Network intrusion detection system (IDS)              | [https://www.snort.org](https://www.snort.org/)                                                                | Rule-based detection                      |
| OpenVAS / Greenbone     | Vulnerability scanning platform                       | [https://www.greenbone.net](https://www.greenbone.net/)                                                        | Enterprise-style vulnerability scans      |
| Linux Exploit Suggester | Suggests kernel exploits                              | [https://github.com/The-Z-Labs/linux-exploit-suggester](https://github.com/The-Z-Labs/linux-exploit-suggester) | Match kernel versions carefully           |
