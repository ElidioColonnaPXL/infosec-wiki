# Nmap

Nmap is a network-mapping tool for identifying reachable hosts, exposed ports, and observable service characteristics. Use it only against assets covered by explicit authorization, and choose timing and probe intensity appropriate for the environment.

## Core phases

- **Target selection** accepts individual hosts, documented ranges, or an input list.
- **Host discovery** checks whether systems appear reachable before deeper probing.
- **Port scanning** tests selected TCP or UDP ports and reports states such as open, closed, or filtered.
- **Service detection** sends additional probes to estimate the application and version behind a port.
- **OS detection** compares network behavior with known fingerprints; treat the result as an estimate.
- **Nmap Scripting Engine** scripts add protocol checks and enrichment. Review a script before use because some categories are intrusive.

## Conservative examples

```bash
nmap -sn 192.0.2.0/28
nmap -sT -p 22,80,443 192.0.2.10
nmap -sV --version-light -p 443 192.0.2.10
nmap -oA inventory-web -p 80,443 -iL approved-hosts.txt
```

## Interpreting results

A port state describes what Nmap observed from its vantage point, not an absolute property of the host. Firewalls, load balancers, rate limiting, packet loss, routing, and source location can change the result. Validate important findings with a protocol-appropriate client and correlate them with asset-owner records.

Preserve the exact command, Nmap version, target source, start and end times, and all normal, XML, and grepable output generated by `-oA`. Begin narrowly, monitor impact, and expand only within the approved plan.
