# .NET Framework

> **Note:**
> Microsoft managed runtime and class-library platform used by PowerShell and many Windows applications.

## Relevance to analysts

- PowerShell exposes .NET objects instead of only text streams.
- Managed assemblies can be inspected through metadata, IL and runtime telemetry.
- Relevant evidence includes assembly loads, CLR activity, PowerShell Script Block Logging and process ancestry.
