# Netcat

> **Note:**
> General-purpose TCP/UDP client and listener for connectivity tests, banner collection and controlled data transfer.

```bash
nc -nv 192.0.2.10 80
nc -lvnp 9001
```

> **Use only on systems and networks where the activity is authorized. Netcat traffic is normally unencrypted.:**
